# Changelog

## 0.9.0 — code135 — first public beta candidate

- Public project identity: TwinGrid, retaining the compatible Android package and certificate.
- DS-inspired dual-screen interface for RG DS.
- Folder, genre, search, favorites and recent browsing.
- Offline bilingual metadata, automatic organization and runtime box-art downloads.
- Guided setup, optional save-folder association and scanning progress.
- Android DraStic launch integration with diagnostics and explicit compatibility limits.
- code135 removes the overlapping overview footer from the genre grid; other library page footers remain unchanged.

This is a pre-release. Stock firmware 1.18 is the tested target; GammaOS remains
unverified. code135's targeted validation builds on the historical code134 core
regression. See [validation scope](docs/VALIDATION.md). Publication status is
tracked by the actual GitHub Release, not inferred from this changelog.
