# TwinGrid 0.9.0 Beta — code135

The first public beta of TwinGrid, a Nintendo DS-focused dual-screen frontend
for Anbernic RG DS. Includes folder/genre/search browsing, offline bilingual
metadata, runtime box art and Android DraStic integration.

**Tested target:** RG DS, stock firmware 1.18, Android 14. code135 has targeted
installed UI and data-preservation checks; broad core/launch evidence is from
code134. GammaOS has not been fully verified. Other DraStic builds may need
manual setup, open only the emulator menu or be unsupported.

Download `TwinGrid-0.9.0-code135.apk`, install and select your NDS folder.
The optional save folder shows save associations. This official file preserves
the original package and certificate for in-place updates of compatible test
builds. Do not uninstall an existing installation to bypass a signature mismatch.
Save in-game before switching titles; launch integration can replace the
emulator task.

No ROMs, BIOS or DraStic are included. The offline catalog is already in the APK.
